AutoCaption v1.1.1

v1.1.1: VBScript 없는 PC에서도 동작, 설치 결과를 정확히 안내, 필요한 프로그램 자동 설치 개선, AI 교정 없이 반복되는 구절 정리

사용 조건: Windows 10/11 · Premiere Pro 25.6 이상 (Mac은 지원하지 않습니다)
필요한 프로그램(Node.js, Python, ffmpeg 등)은 설치 파일이 자동으로 설치합니다. 인터넷 연결이 필요해요.

설치 파일 내려받기 (v1.1.1)

  1. 압축을 전부 풉니다.
  2. install.bat을 더블클릭합니다.
  3. Premiere Pro를 다시 시작하고 Window > UXP Plugins > AutoCaption을 엽니다.

이미 설치한 사람은 패널을 열면 자동 업데이트 안내가 뜹니다.
